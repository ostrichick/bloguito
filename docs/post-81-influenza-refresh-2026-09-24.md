## 제목 변경 보호장치

기존 공개 글 updater는 제목을 항상 보존하도록 설계되어 있어, 이번처럼 사용자가 제목 표현 변경까지 승인한 경우에도 preflight가 차단했다. 일반 안전성을 유지하면서 다음 조건을 추가했다.

- 기본 `update-existing` 동작은 계속 제목 변경을 거부한다.
- `--confirm-title-change`를 별도로 지정한 경우에만 검토된 `plan.title`을 적용한다.
- SSH 전송 계층은 검토된 정확한 제목 외의 `--post_title` 값을 거부한다.
- 제목만 변경되는 경우도 업데이트를 생략하지 않는다.
- 제목 변경 뒤에도 기존 슬러그·공개 상태·본문 및 허용된 발췌문 외 메타데이터 보존을 검증한다.

이 경로는 관련 updater, 승인 preflight, SSH bridge 테스트로 회귀 검증했다.
