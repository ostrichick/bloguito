### `agent-publisher/agents/designer.py`

- 기존 전체 제목 중심 타이포 카드와 범용 스톡 배너를 신규 라우팅에서 제거하고 관련 비활성 렌더러도 삭제했다.
- 신규 기본 경로는 `현대적 에디토리얼 커버` 하나로 통일했다.
- 검색 키워드는 글 제목 안에 같은 구문이 실제 존재할 때만 커버 제목 후보로 사용한다. curator의 힌트나 별도 키워드에서 금액·혜택을 새로 만들지 않는다.
- 제목 전체 대신 짧은 핵심 제목과, 제목 안에서 명확히 분리되는 경우에만 짧은 보조 문구를 만든다. 자동 보조 문구에는 숫자를 넣지 않는다.
- 생성 모델에는 글자를 그리지 말고 오른쪽 중심 장면과 왼쪽 여백만 만들도록 표준 프롬프트를 전달한다. 한글은 로컬 폰트로 후처리한다.
- 후처리 한글 폰트는 나눔·Noto CJK/KR·맑은고딕 후보 중 실제 서로 다른 한글 글리프가 확인된 폰트만 사용한다. 한글 가능 폰트가 없으면 Pillow 기본 폰트로 조용히 대체하지 않고 실패시켜 깨진 한글 대표 이미지의 등록을 막는다.
- 이미지 모델은 `BLOGUITO_IMAGE_MODEL` 환경변수로 교체할 수 있다. 기본 경로는 2026-09-27 Google 공식 문서에서 GA로 확인한 `gemini-3.1-flash-image`를 `generate_content`로 호출하며 16:9, 1K 장면을 요청한다. 과거 저장소의 `imagen-3.0-generate-002` 예시는 이미 종료된 모델이라 신규 경로에서 제거했다. 이번 작업에서는 실제 유료/외부 이미지 생성 호출을 실행하지 않았다.
- 생성 장면은 곧바로 저장하지 않는다. `gemini-3.5-flash` 비전 검수로 주제 인지, 중심 피사체, 허용된 텍스트 외의 가짜 글자·로고, 얼굴·손·피사체 잘림, 모바일 인지성, 구식 배너/전단지 인상을 확인한다. 실패하면 검수 사유를 다음 생성 프롬프트에 넣어 최대 2회까지 재생성한다.
- 이미지 생성 API가 실패하면 전체 SEO 제목을 되살리지 않고 같은 짧은 카피의 미니멀 커버로 폴백한다.
- 공연은 별도 검토된 공식 포스터가 있을 때만 원본 보존형 경로를 사용한다. 포스터를 강제 중앙 크롭하지 않고 원본 비율을 유지해 전경에 놓고, 같은 원본을 흐림 배경으로 확장한다. 공식 포스터 위에는 블로그 제목·브랜드 배지를 다시 덮지 않는다.
- 공식 공연 커버도 비전 검수를 통과해야 사용한다. 검수 모델을 사용할 수 없거나 얼굴·머리·턱·공연명 보존 기준을 통과하지 못하면 공식 이미지를 그대로 사용하지 않고 일반 에디토리얼 커버 경로로 폴백한다. 비전 검수 자체가 불가능한 생성 장면 역시 사용하지 않고 코드가 직접 그리는 결정적 미니멀 커버를 사용한다.

### 공연 공식 이미지 전달 경로

기존 `curator.py`는 NOL 공식 상품에서 포스터 URL을 얻어도 일반 기사 `og:image`와 같은 `poster_url` 필드에 섞었고 `main.py`는 `DesignerAgent`의 `reviewed_poster_url` 인자를 전달하지 않았다. 이번 변경으로 **공연명·지역·공연일이 유일하게 일치해 `ticket_verification.status=matched`가 된 공식 NOL 상품의 포스터만** `reviewed_poster_url`로 승격하고 `main.py`가 이를 디자이너에 전달한다. 일반 기사 `og:image`나 자체 선언 필드는 자동 공식 포스터로 신뢰하지 않는다. 기획사·아티스트 공식 이미지는 수동 작업에서 별도 검토 후 명시적으로 전달할 수 있으며, 자동 수집 범위를 넓히려면 출처 검증을 먼저 추가해야 한다.

## 품질 검수 기준

대표 이미지는 생성 직후 자동으로 품질이 확정된 것으로 보지 않는다. 저장·업로드 전 실제 결과에서 다음을 확인한다.

1. 주제를 한눈에 알아볼 수 있는가.
2. 중심 피사체가 하나의 장면으로 명확한가.
3. 텍스트가 핵심 제목과 선택적 보조문구 범위를 넘지 않는가.
4. 한글 글자가 정확하고 깨지지 않았는가.
5. `65세 이상` 같은 의미 단위가 어색하게 분리되지 않았는가.
6. 얼굴·머리·손·문서·제품이 이미지 경계에서 잘리지 않았는가.
7. 모바일 썸네일에서 제목과 주제가 인식되는가.
8. 데스크톱에서 피사체와 여백의 균형이 자연스러운가.
9. 오래된 블로그 배너·전단지·관공서 홍보물처럼 보이지 않는가.
10. 본문 제목과 세부정보를 이미지가 장황하게 반복하지 않는가.

얼굴 잘림, 글자 오류, 부자연스러운 인물·손, 텍스트 과밀, 저품질 클립아트, 구식 배너 디자인이 심하면 재생성 또는 재편집한다.

## 기존 이미지 교체 판단

이번 작업에서는 교체하지 않았다. 전체 일괄 교체도 먼저 할 필요는 없다. 대표 이미지 변경은 기존 검색·공유 카드와 시각적 연속성에 영향을 주며, 이미 괜찮은 공식 공연 이미지나 최근 개선본까지 다시 만들 이유가 없다.

향후 별도 작업으로 교체한다면 다음 순서를 권장한다.

1. **P1:** 한글 오류·깨짐·잘린 얼굴·잘못된 날짜/가격/연령처럼 현재 본문과 충돌하는 이미지.
2. **P2:** 화면 대부분이 작은 글자·체크리스트·여러 가격으로 채워져 모바일에서 읽히지 않는 구식 정보 배너.
3. **P3:** 공식 공연 포스터를 과도하게 크롭해 얼굴·공연명이 잘린 이미지.
4. **P4:** 정보는 맞지만 시각 스타일만 오래된 이미지. 트래픽·노출이 높은 글부터 점진 교체한다.

이미 전입신고 수준에 가깝거나 최근 짧은 제목으로 개선된 이미지, 공식 홍보물을 잘 보존한 공연 이미지는 우선 교체 대상에서 제외한다.
