- **사실 확인 제한:** 일부 원문 접근 오류·동적 서비스·지역별 시간/재고·상충하는 의료 접종 연령/기관 적용범위를 임의로 확정하지 않았다. 20편 비교 화면은 정식 `source → review → check` 후의 발행 가능성을 자동 인증하지 않는다.
- **운영 중 동시 편집:** 승인 시점까지 원문·공식 자료·목차 대상/활성 플러그인이 바뀌면 이 후보의 현재성은 만료된다. 해시/CAS 불일치 때 자동 병합·강제 복구하지 않고 재검토한다.
