# 검색 의도 중심 자동화 (2026-09-13)

사용자 피드백에 따라 일반적인 안내글보다 하나의 대상과 구체적인 검색 질문을 해결하는 글을 우선한다.

## 적용 코드

Radar는 기존 광범위한 config 키워드 대신 data/search_briefs.json의 승인된 주제만 탐색한다. 대상명, 대표 키워드, 질문, 설명 방향, 공식 출처, 검색 결과 URL, 검토일/만료일을 기록한다. 만료/미승인 주제와 제목의 필수 대상·지역이 불일치하는 뉴스, 동일 실행의 중복 URL은 제외한다. 검토 주제가 없으면 일반 키워드로 돌아가지 않고 보류한다. 현재 생활/건강 카테고리는 승인 주제가 없다.

검색 결과 검토는 사람이 웹 도구로 수행하고 brief에 기록한다. 이번 검색은 사용 가능한 웹 검색 도구 결과이며 Google 개인화 검색 화면/검색량/순위 난이도를 측정한 것이 아니다. 검색량과 클릭수는 미측정으로 둔다. 자동 키워드 연구 API와 Search Console은 아직 연결하지 않았다.

## 원고 기준

1. 대표 검색어와 주된 질문 하나를 정한다. 공연명+지역+예매, 사업명+연도+기간 등으로 구체화한다.
2. 공식 정보와 기존 설명글을 비교해 독자에게 도움이 되는 차이를 정한다. 검색 결과 존재만으로 유입을 보장하지 않는다.
3. 제목·첫 문단에서 답부터 제공한다. 숫자·조건은 공식 출처와 함께 제시하고 미확인 정보는 지어내지 않는다.
4. 오픈 예정/신청 중/마감을 구분한다. 검토 기한 후에는 최신 정보를 확인할 때까지 주제를 보류한다.
5. 동일 대상의 기존 글과 검색 의도가 겹치면 공개 전에 통합/갱신 여부를 결정한다. 이번 수원 글은 과거 공개 글과 겹칠 수 있는 검토 샘플이며 중복 공개하지 않는다.

## 정보의 유효 수명 (2026-09-14 추가)

사용자 지적: 신청 마감이 이틀 남은 근로장려금 글은 검색 유입용 신규 콘텐츠로 적절하지 않다. 접수 중이라는 사실과 새 글을 작성할 가치는 별개다.

- 주제 검토 시 `검색 질문`, `그 답이 필요한 마지막 날짜`, `남은 기간`, `기존 글과 중복 여부`를 함께 기록한다.
- 신규 검색 유입용 글은 마감이 오늘·내일인 주제를 제외한다. 접수 가능 여부 검사 통과만으로 주제를 승인하지 않는다.
- 마감 없는 반복 질문을 우선한다. 일정형 콘텐츠는 검색 발견까지 걸릴 시간을 고려해 선택하고, 행사 종료 후 유지할 가치가 있는지도 구분한다. 색인 소요 기간이나 검색량을 측정한 것처럼 단정하지 않는다.
- 이번에는 근로장려금 초안을 등록 전에 제외하고, 서초구 소형가전 배출 방법으로 교체했다. JX 인천 공연의 결제 방식 글은 10월 9~11일 공연 전까지 쓰이는 일정형 콘텐츠로 별도 분류한다.

이 기준은 편집 문서와 이번 수동 주제 선정에 반영했다. 자동 파이프라인의 기간 판정 코드에 최소 잔여기간 필터를 추가하거나 운영 크론을 변경한 것은 아니다.
