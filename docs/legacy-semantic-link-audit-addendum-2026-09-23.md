### 외부 링크 관련 추가 한계

- 두 독감 글 모두 9/16 KDCA PDF는 **원본과 동일 href로 보존**했고 이 URL의 신규 GET은 HTTP 200·PDF 응답이다. 8/25 원 발표 URL은 새로 추가된 **공식 출처**이지만 원문 자체에 9/16 수정 전의 예전 시작일이 있으므로 이를 최신 시작일 증거로 재해석하지 않는다. 신규 본문은 9/16 수정 일정을 설명하고 원 발표는 절기 종료·출생범위 등 변경되지 않은 사실용으로 사용한다. 원 출처 제목에 `8/25 원 발표(9/16 일정 정정 전)`과 같은 출처 맥락을 명시할지는 담당자가 검토할 사항이지 현재 확인된 사실 오류의 단정이 아니다.
