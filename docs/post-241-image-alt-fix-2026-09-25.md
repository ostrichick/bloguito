# #241 대표 이미지 alt 보완 — 2026-09-25

## 요청

네이버/SEO 점검 화면에서 `https://lifeinfo24.org/wp-content/uploads/2026/09/thumb_insurance_car_2026.jpg`의 Alt 속성 누락 1건이 표시되어 수정했다.

## 확인된 상태

- 대상 이미지는 WordPress 첨부 ID `242`이며 공개 글 `#241`의 대표 이미지(`_thumbnail_id=242`)다.
- 대상 글 제목은 `명절 교대운전 보험 확인: 단기운전자확대특약과 원데이보험의 효력 시작 시점`이다.
- 수정 전 첨부 메타 `_wp_attachment_image_alt`는 빈 값이었고 공개 HTML의 대표 이미지도 `alt=""`로 출력됐다.
- 이미지는 본문 `post_content`에 직접 삽입된 것이 아니라 대표 이미지로 출력되고 있어 본문 수정은 필요하지 않았다.

## 변경

- 첨부 ID `242`의 `_wp_attachment_image_alt`만 다음 값으로 설정했다.
  - `단기운전자확대특약과 원데이보험 비교 안내`
- 부모 글 #241의 제목, 본문, 카테고리, 공개 상태는 변경하지 않았다.

## 검증

- WordPress REST media 응답에서 `alt_text`가 `단기운전자확대특약과 원데이보험 비교 안내`로 확인됐다.
- 공개 글 HTML의 대표 이미지가 `alt="단기운전자확대특약과 원데이보험 비교 안내"`로 렌더링되는 것을 캐시 우회 요청과 일반 URL 요청 모두에서 확인했다.
- 글 #241은 계속 `publish` 상태이며 `post_modified`는 `2026-09-24 16:08:32`로 유지되어 이미지 메타 수정이 부모 글 본문 수정으로 기록되지 않았음을 확인했다.

## 롤백

문제가 생기면 첨부 ID `242`의 `_wp_attachment_image_alt`를 빈 값으로 되돌리면 된다. 본문 롤백은 필요하지 않다.
