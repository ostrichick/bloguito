# 카테고리 설명의 불필요한 독자·장르 제한 제거 — 2026-09-21

## 요청과 변경 범위

- 사용자 요청: 카테고리 소개에 `중장년층을 위한`, `트로트 가수` 등 특정 연령이나 장르를 전면에 내세워 잠재 독자를 제한하지 말 것.
- 작업 시작 기준 Git HEAD: `de1e735`. 기존 작업자의 미커밋 파일은 수정하지 않음.
- WordPress의 기존 카테고리 2개에서 **설명(description)만** 변경. 이름, ID, 슬러그, 게시물, 글 분류, 자동화 키워드는 변경하지 않음.

| ID / 슬러그 | 기존 설명 | 새 설명 |
| --- | --- | --- |
| `4` / `life-health` | 중장년층을 위한 일상 생활 상식과 건강 관리 꿀팁 | 일상생활에 필요한 유용한 정보와 건강 관리 방법을 알기 쉽게 안내합니다. |
| `2` / `concert` | 트로트 가수 콘서트, 티켓팅 일정 및 예매 방법 안내 | 콘서트·뮤지컬·연극·페스티벌 등 공연 일정과 티켓 예매 방법을 안내합니다. |

## 적용·확인

- 운영 서버 `bloguito`의 WordPress `wordpress_app`에서 수정 전 카테고리 ID·이름·슬러그·설명을 `wp term get/list`로 읽고 두 카테고리의 설명 필드만 `wp term update category <ID> --description=...`로 변경. 두 명령 모두 `Success: Term updated.` 반환.
- 운영 DB의 `wp term list category --format=json` 재조회에서 두 설명의 정확한 변경을 확인. 공개 REST API `/wp-json/wp/v2/categories/4` 및 `/2` 응답에서도 새로운 설명과의 문자열 일치 확인.
- 공개 `/category/life-health/`, `/category/concert/` 각각 HTTP 200 및 **새 문구 존재 / 기존 연령·장르 제한 문구 없음** 확인. 확인 시 캐시 확인용 쿼리 문자열 사용.
- 별도 애플리케이션 코드 배포·컨테이너 재시작 없음. 롤백 시 위 표의 기존 설명으로 해당 카테고리 `description`만 다시 변경.

## 향후 편집 원칙

카테고리와 사이트의 범용 소개는 확인되지 않은 방문자 연령·성별·특정 아티스트/장르로 대상 독자를 단정하거나 범위를 좁히지 않는다. 실제로 자격조건이나 장르가 중요한 **개별 글**에서는 공식 근거에 따라 필요한 대상·조건·장르를 정확하게 명시한다.
