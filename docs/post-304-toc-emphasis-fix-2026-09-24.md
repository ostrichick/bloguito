## 원인과 수정

현재 공통 렌더러는 이미 `procedure` 섹션이 둘 이상일 때만 STEP 번호를 붙이도록 되어 있었으나, #304는 그 개선 이전 HTML이 WordPress에 저장되어 있어 단독 `STEP 1`이 남아 있었다. 최신 검토 원고를 현재 렌더러로 다시 렌더링하면서 목차와 본문에서 해당 배지를 제거했다.

본문의 중요한 확인 대상을 안전하게 강조할 수 있도록 구조화 문단에 선택적 `emphasis` 배열을 추가했다. 강조 문구는 반드시 해당 검토 문단의 실제 텍스트에 존재해야 하며 1~5개, 각 2~80자 범위만 허용한다. 렌더러는 지정된 문자열만 HTML escape 후 `<strong>`으로 감싼다. 임의 HTML이나 Markdown을 원고에 넣는 방식은 사용하지 않는다.

#304에서 지정한 강조 문구는 정확히 다음 한 곳이다.

`가까운 행정복지센터나 공동주택 수거함`
