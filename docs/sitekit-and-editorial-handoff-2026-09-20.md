# Bloguito 운영 변경 인계 — 2026-09-20

## Git에 반영한 코드
- 편집 원고의 자동 내부 추천 링크에 기존 서버 IP/HTTP 주소가 아닌 `https://lifeinfo24.org` 정식 공개 주소만 사용한다.
- 제목의 구체적인 주제어가 겹치지 않는 무관한 글은 같은 카테고리더라도 추천하지 않는다. 필터는 보수적인 휴리스틱이며 전체 검색 의도 평가를 대체하지 않는다.
- 기존 임시글에서 자동으로 생성된 추천 카드만 바뀌었다면, 글 내용이 동일한지 확인한 뒤 재렌더링할 수 있다. 작성자 본문 편집이 감지되면 기존 보호 장치를 유지한다.
- 날짜형 `temporal_source` 필드가 없는 에버그린 임시글의 재렌더링 시 검토 다이제스트 생성 오류를 수정하고, 관련 테스트를 갱신했다.

## WordPress 운영 상태 — 읽기 전용 확인 결과
- Site Kit by Google `1.187.0`: 활성. 플러그인 본체, WordPress 데이터베이스 설정 및 Google 계정 연결은 Git 코드 커밋에 포함되지 않는다.
- 이전 개별 GA4 측정 ID 옵션 `ga4_measurement_id`는 빈 값이며, Site Kit과 별도로 삽입하던 옛 설정은 비활성화돼 있다.
- 개인정보처리방침은 WordPress 페이지 #21이며 공개 상태이고, 본문의 초록색 '핵심 요약' 박스는 제거돼 있다. 실제 페이지 본문 및 설정은 WordPress DB에 있으며 본 저장소에 자동 동기화되지 않는다.
- 2026-09-20 점검에서 캐시된 홈페이지 HTML에는 `googletagmanager.com/gtag/js` 요청 태그가 없었으나, 개인정보처리방침 HTML에는 **Site Kit이 삽입한 GA 태그가 하나** 확인됐다. 방침 본문은 아직 'GA4 측정 태그 비활성화'라고 설명하므로 운영 상태와 맞지 않는다. 변경 이전/이후의 실제 GA4 데이터 수집 성공은 검증하지 못했다.
- 이 불일치는 **해결 완료가 아니다**. 공개 화면별 Site Kit 태그 삽입 여부, 캐시 무효화, GA4 기존 속성 연결 및 중복 이벤트, 방침의 현재 계측 설명을 함께 대조한 다음 수정·재검증해야 한다. 본 커밋은 WordPress 계정 연결·태그·방침을 추가 변경하지 않는다.
- ChatGPT 관리 루틴 예약은 서비스 내부 작업이며 Git으로 내보내지지 않는다. 백업 원본, 계정 인증정보 및 작업용 운영 DB 스냅샷은 Git에 포함하지 않는다.
