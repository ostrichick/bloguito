# Bloguito 태그 거버넌스 정리 — 2026-09-26

## 원칙

기존 `post_tag` 데이터와 글-태그 관계는 보존한다. 공개 글의 태그 UI는 이미 숨겨져 있고 태그 아카이브는 `noindex,follow`이므로, 이번 정리의 목적은 과거 1회성 태그를 대량 삭제하는 것이 아니라 **새 일회성 태그의 증가를 멈추고 기존 태그를 관리 가능한 상태로 분류하는 것**이다.

현재 편집 파이프라인은 새 원고를 `tags: []`로 만들며 WordPress 생성 명령에도 태그 인수를 전달하지 않는다. `PublisherAgent`는 이제 비어 있지 않은 태그가 들어오면 WordPress I/O 전에 `editorial_tags_disabled`로 중단한다. 따라서 과거 태그는 그대로 남고 신규 자동 태그만 닫힌다.


분류는 `scripts/audit_tag_governance.py`가 수행하며 WordPress를 변경하지 않는다. 결과 파일은 `tmp/tag-governance-20260926.json`, `tmp/tag-governance-20260926.csv`에 생성한다.

## 운영 정책

1. 자동 편집/발행 경로는 신규 `post_tag`를 만들지 않는다.
2. 기존 258개 태그와 기존 글 관계는 이번 정리에서 삭제·재배치하지 않는다.
3. `삭제 후보` 61개 역시 즉시 삭제하지 않는다. 향후 수동 정리 창에서 참조/리디렉션 필요성을 따로 확인한 뒤 처리한다.
4. 동일 표기 `통합 후보`도 자동 병합하지 않는다. WordPress 관계 변경은 별도 검토와 백업 이후에만 수행한다.
5. 추석 관련 글 비중 자체는 문제로 취급하지 않는다. 이 문서의 태그 정리는 콘텐츠 주제 비중 조정과 무관하다.
