# 중복 주제와 검증 전가 오류 수정

사용자 지적: 공개한 무명전설 수원 공연을 다시 임시글로 만들었고, 구매 가능 여부·주차·시야 등의 확인을 독자에게 넘겼다. 이는 편집 책임의 오류다. 검색 결과 확인 전에 기존 게시물 확인을 누락한 수동 작업에도 원인이 있다.

서버 확인 결과 공개 글 70과 임시글 89가 같은 공연이었다. 중복 초안 89는 영구 삭제하지 않고 휴지통으로 이동했다. 원래 공개 글 70은 변경하지 않았다.

공식 NOL 상품 26013136 재확인 결과 2026-09-13 현재 오픈 예정이며 시작 시각은 9월 15일 13시다. 따라서 '현재 구매 불가, 9월 15일 오후 1시 오픈 예정'으로 답해야 한다. 이 문장을 '사이트에 가서 구매 가능한지 확인'으로 대체하지 않는다.

## 편집 원칙

- 확인한 사실은 확인 기준일과 함께 직접 답한다. 출처 링크는 근거 또는 구매·신청 경로다.
- 미확인 부가 정보(주차, 좌석별 시야, 남은 재고)는 FAQ를 만들거나 확인 요청으로 채우지 않는다.
- 글의 핵심 질문을 검증할 수 없으면 항목을 숨겨 완성된 것처럼 발행하지 않고 글 자체를 보류한다.
- 개인별 자격 등 독자의 정보가 필요한 사항은 객관적 조건을 제시하되 개인별 결과를 보장하지 않는다.

## 코드 변경

main 실행 시작에 WordPress의 공개/초안/검토대기/예약/비공개 글 목록을 동기화한다. 동기화 실패 시 파이프라인을 중단한다. Radar 주제 선택은 당일 목록을 요구하고, 같은 대상·지역 등 필수 제목 용어(공백·문장부호·앙코르 표기 정규화) 또는 동일 공식 URL이 이미 있으면 제외한다. 목록 누락·오래된 목록은 중복 없음으로 처리하지 않는다. 공개 글뿐 아니라 검토 중인 초안도 중복 대상이다. 휴지통은 제외한다.

이 검사는 동일 상품/주제 재선정 방지이며 동시 실행 두 개의 경쟁을 잠그는 장치는 아니다. 공식 사이트의 공통 안내 URL을 공유하는 다른 주제도 보수적으로 제외될 수 있다. 새 대상명이 기존 제목에 전혀 없고 공식 URL도 없으면 놓칠 수 있다.

본문 고정 안내에서 '출처에서 확인하세요'라는 검증 전가 문구를 제거했고 Copywriter에도 미확인 부가정보·FAQ 금지 규칙을 명시했다. 기존 사실 대조 및 핵심 기간 검증을 유지한다.

전체 회귀 테스트 67개 통과. 기존 제목의 표기 변경, 다른 지역, 동일 상품 URL, 초안/휴지통 구분, 게시물 목록 누락을 검사했다. 코드 변경은 로컬/GitHub 반영이며 운영 파이프라인 배포는 별도다. 서버에서 수행한 변경은 중복 초안의 휴지통 이동과 초안 색인 정리다.
