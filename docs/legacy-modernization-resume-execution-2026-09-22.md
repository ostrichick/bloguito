## 백업·되돌리기

각 정규 updater는 `agent-publisher/data/editorial_runs/` 안에 글별 전체 원본 백업을 쓰고 갱신한 본문을 바로 재조회한다. 앞선 승인 폴더의 `post-original.PRIVATE.json`은 외부 공개와 Git에서 제외한다. 되돌릴 때는 **운영의 현재 본문 SHA가 위 새 본문 SHA와 일치하는지 새로 확인한 경우에만** 해당 글의 백업을 사용하며, 다른 편집자가 수정한 상태를 덮어쓰지 않는다. 전체 사이트 복구 스크립트는 단일 글 복원에 쓰지 않는다.

이 문서의 후속 결과는 각 실제 완료 뒤 갱신한다.
