## 홈택스 브라우저 GET와 실제 서비스 도착

1. #137 게시물의 현재 행동 링크 `https://www.hometax.go.kr/`를 로그인하지 않은 같은 격리 브라우저에서 **GET 탐색**했다. 주 문서 `https://www.hometax.go.kr/` HTTP **200** `text/html` 뒤 WebSquare 페이지 `https://hometax.go.kr/websquare/websquare.html?w2xPath=/ui/pp/index_pp.xml` 역시 HTTP **200** `text/html`. 최종 주소는 `&menuCd=index3`가 붙은 형태, 문서 제목 `국세청 홈택스 - 메인`, `readyState=complete`. 실제 본문에 `근로·자녀장려금`, `정기 심사진행상황 조회`, `로그인` 메뉴가 나타났다. 현재 게시물 버튼은 상세 조회 화면에 바로 연결하지 않고 홈택스 첫 화면으로 이동한다.
2. 별도 확인을 요청받은 정확한 주소 `https://mob.tbwf.hometax.go.kr/jsonAction.do?actionId=UTEWFMBA09F001`도 브라우저 주소창 탐색과 같은 **GET**으로 열었다. 주 문서 HTTP **200**, MIME `text/html`, 최종 주소 동일, 제목 `국세청 차세대 모바일`, `readyState=complete`. 실제 본문에는 `근로장려금 반기 심사진행상황 조회`, `귀속년도 2019`, `조회구분 상반기`, `조회`가 렌더되었고, 동시에 `로그인이 필요한 화면입니다. 로그인 페이지로 이동합니다. 확인` 안내가 노출됐다. 폼의 `method=post`, `action`은 같은 `jsonAction.do?actionId=UTEWFMBA09F001` 경로다. **GET은 JSON 에러가 아니라 HTML 화면으로 렌더되지만 실제 조회는 로그인 필요**. 표시된 `2019`는 비로그인 상태의 화면 기본값으로만 관측했으며 2026년 귀속 선택·조회 가능 여부는 확인하지 않았다. `확인`·로그인·조회·제출은 클릭하지 않았다.

## 콘솔·네트워크 및 증거 제한

- #85, #137, #225에서 브라우저 로그 `Failed to load resource: net::ERR_BLOCKED_BY_CLIENT` 각각 1건. 추적한 실패 URL은 모두 `https://lifeinfo24.org/wp-content/plugins/wp-statistics/assets/js/tracker.js?ver=14.16.13`로, 격리 Edge의 클라이언트 차단이다. 이 로그만으로 사이트 원서버 스크립트 자체 장애나 독자 브라우저의 동일 현상을 단정할 수 없다. 세 글의 주요 문서는 HTTP 200, 본문 DOM은 생성됐다.
- 위 두 번째 홈택스 상세 경로에서 `ERR_BLOCKED_BY_CLIENT` 1건 및 HTTP **404** 리소스 1건의 콘솔 로그를 보았으나, 해당 리소스 URL과 UI 기능 영향은 확인하지 못했다. 메인 문서는 HTTP 200이고 로그인 안내가 표시됐다. 일반 홈택스 루트에서도 클라이언트 차단 리소스 로그 1건 발생. 홈페이지 초기 요청에서는 이 로그의 정확한 대상 URL을 캡처하지 못했다.
- `zoom:200%`는 실제 브라우저 확대 기능 대신 문서 CSS 확대를 사용한 근사 테스트다. 200% 캡처 첫 시도가 시간 초과됐으며 성공했다고 보고하지 않는다. CDP 측정에서 각 페이지의 문서 폭은 1265px 이내였지만 접근성 적합성 인증은 아니다.
- 실제 화면 캡처 **8개 파일 생성 및 파일 크기 확인**. 경로(사용자 OS 임시 폴더, Git에 미포함): `%TEMP%\bloguito-browser-qa-20260922-worker2\` 아래 `home-390-top.png`, `post85-360-table1.png`, `post85-360-table2.png`, `post85-390-top.png`, `post137-390-top.png`, `post137-360-summary.png`, `post225-390-top.png`, `post225-360-summary.png`. #85 표 2개·홈·#137·#225 첫 화면은 별도 이미지 조회로 시각 확인했다. 임시 경로 자료는 OS 청소 정책에 따라 사라질 수 있다.
