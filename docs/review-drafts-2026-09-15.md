사용자의 짧은 요청 “글 두개 작성해줘”에 공통 편집 시스템을 적용했다. 현재 WordPress 공개·임시·예약·검토·비공개 글 목록을 조회한 뒤 기존 글과 겹치지 않는 상시 생활 질문을 선정했다. 검색 결과는 검토했지만 검색량·순위·유입은 측정하지 않았다. 마감 임박 행사나 신청 공고를 새 글로 선정하지 않았다.

## 112 — 온라인 여권 재발급 수령 준비물: 성인 대리수령·우편배송·수령기관 변경 가능할까?

- 검색 질문: 온라인 여권 재발급 후 누가, 어디서, 무엇을 지참해 수령하는가?
- 국내 수령에 범위를 한정하고 성인 본인 방문과 법정대리인이 온라인 신청한 미성년자의 수령 예외를 구분했다.
- 준비물, 수령기관 변경 제한, 온라인 재발급의 우편배송 제외를 설명했다. 신청 자격 전체나 해외 입국 규정으로 주제를 넓히지 않았다.
- 공식 근거: https://passport.go.kr/home/kor/contents.do?menuPos=11 및 https://passport.go.kr/home/kor/contents.do?menuPos=44
- 검색에서 발견한 지자체 문서는 미성년자 온라인 신청 정보를 아직 갱신하지 않은 부분이 있어 원고의 사실 근거로 쓰지 않고 최신 외교부 안내를 사용했다.
- 상태: draft. 미리보기 경로: `/?p=112&preview=true`.

## 113 — 우체국 주거이전 전송서비스 연장 방법: 유료 신청 건의 기한·요금

- 검색 질문: 전입신고 때 신청한 개인 유료 우편물 전입지 전송서비스를 어디서 언제까지 연장하는가?
- 인터넷우체국의 실제 서비스 안내에서 해당 유료 신청 건의 절차와 개인 수수료를 확인했다. 다른 메뉴의 인터넷 직접 신청/기간 추가와 혼동하지 않도록 제목·첫 문단·FAQ에 범위를 명시했다.
- 별도 송달장소 신고가 필요한 소송 관련 예외를 보존했다. 반복되는 마감 설명 문단은 줄이고 다시 검토했다.
- 공식 근거: https://service.epost.go.kr/front.RetrieveAddressMoveInfo.postal

## 작성·검증 경로

공식 URL에서 원문을 수집하고 문단별 인용·질문 ID를 갖는 bundle을 작성했다. 두 원고 모두 로컬 `editorial_cli.py review`를 통과했다. 우편 글은 중복 문단 정리 후 재검토했다.

운영 서버의 `editorial_cli.py publish`를 각각 실행하여 실제 WordPress 목록 재조회, 별도 모델 재검토, 코드 검사, 임시글 저장을 거쳤다. 두 실행 모두 ready를 반환했고 Publisher의 저장 본문 비교를 통과했다. 검사를 우회하는 직접 본문 등록은 하지 않았다.

대표 이미지는 자체 제작한 한글 안내 카드다. 본문 등록 후 미디어만 추가했고 원고 본문과 제목을 변경하지 않았다. 별도 재조회에서 draft 상태와 준비 원고의 본문 일치를 확인했다. 관리자 로그인 브라우저에서의 렌더링 검증은 수행하지 않았다.

대표 이미지 ID는 여권 글 114, 우편 글 115이며 각 글의 `_thumbnail_id`를 재조회해 연결을 확인했다.

원문 snapshot·bundle·모델 검토 결과는 로컬 `tmp/drafts-0915/` 및 서버의 해당 실행 산출물에 보관했다. 두 주제 brief를 `agent-publisher/data/search_briefs.json`에 기록했다. 향후 중복 검사는 실제 등록된 글을 감지해야 하며 재등록하지 않는다.

기존 글은 보존했고 공개 발행은 하지 않았다. 코드 변경 없는 콘텐츠·주제 자료 작업으로 회귀 테스트를 재실행하지 않았다. 다른 작업의 copywriter.py/main.py/notifier.py 미커밋 변경은 이번 커밋에 포함하지 않는다.
