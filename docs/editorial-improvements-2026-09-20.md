# 편집 원고 문구 정리 및 제한적 검사 개선 — 2026-09-20

## 범위와 실제 변경

- `content/draft-revisions-2026-09-20/`의 기존 임시글 원고 **11편**에서 공통 말미 문구인 `자료 검토: ... 링크된 자료의 적용 시점과 실제 안내 화면을 확인해 사용하세요`를 제거하고 `공식 출처 및 검토 기록`을 `공식 출처`로 변경했다. 본문 중 실제 공식 출처 링크와 구체적인 신청·자격·기간·예외 설명은 유지했다. 검토 일시는 이 내부 기록에 보존한다.
- #135에서는 `이 초안`의 발행·통합 결정을 독자용 본문에서 제거하고 이미 있던 종합 안내 #125 링크를 유지했다. #225에서는 `이 원고에서는 확보하지 못했습니다` 등 편집 작업 지시가 포함된 단락을 제거하고 은행별 공고·운영 조건을 구분하는 본문의 나머지 내용을 유지했다. #227에서는 앞선 원고에서 무엇을 삭제했는지 나열한 내부 작업 이력을 제거하고, 실제 감경 조건과 개인별 통지서 구분을 유지했다. #237의 `진입을 안내하지 않습니다`는 독자가 실행할 수 있는 `차량으로 진입하지 마세요`로 바꾸었다.
- `manifest.json`의 **로컬 원고 SHA256 11개만** 새 파일 내용에 맞게 갱신했다. `publication_status=draft`, `review_status=human_final_review_required` 및 나머지 메타데이터는 그대로 유지했다. 이 해시는 로컬 사본 무결성 확인값이다. 운영 WordPress의 기존 본문과 일치한다거나 사람 검토가 완료됐다는 뜻이 아니다.
- `agents/editorial.py`의 새 구조화 원고 검사에 명백한 내부 편집 문구(`이 초안`, `이 원고에서는`, `자료 검토:`, `공식 출처 및 검토 기록` 등)를 막는 좁은 패턴을 추가했다. 공식 출처의 실제 발표일이나 독자에게 필요한 구체적인 예외·실제 정정 설명은 금지하지 않는다. `tests/test_legacy_draft_copy.py`에서 해당 차단, 11개 원고의 출처 유지·상태 미승인·해시 일치를 검사한다.

## 검증

- PowerShell에서 `PYTHONPATH=agent-publisher`, `PYTHONIOENCODING=utf-8` 지정 후 `python -m unittest discover -s agent-publisher/tests -p test_editorial_system.py -q`: **33개 통과**.
- 동일 환경에서 `python -m unittest discover -s agent-publisher/tests -p test_legacy_draft_copy.py -q`: **2개 통과**.
- `python tmp/check_draft_report.py`: `PASS_MANIFEST_SHA256 11`, 기존 README 링크·배너 검사 통과.
- `git diff --check`: 통과. 테스트 중 Windows 기본 CP949 출력으로 기존 테스트 2개가 `UnicodeEncodeError`를 일으켰고, `PYTHONIOENCODING=utf-8` 설정 후 같은 검사가 통과했다.

## 남은 보류·미확인 사항

- 이번 작업은 **로컬 사본 문구만 수정**했다. WordPress DB, 임시글 상태, 공개 글, 실제 사이트, 서버, Git 커밋·푸시는 변경하지 않았다. 기존 운영 임시글에는 종전 문구가 남아 있을 수 있으며, 로컬 새 해시를 운영 본문 해시로 오인하면 안 된다.
- 기존 11편은 독립적 사람이 공식 최신 원문·시행 연도·대상·개별 링크·신청 화면을 확인하고 구조화 bundle로 다시 검토하기 전 공개하지 않는다. 특히 #241 보험 약관, #237 지역별 무료주차장, #233 현행 의약품 품목, #225 은행별 2026년 이동점포, #135의 #125와 중복 여부는 기존 보류 상태 그대로다. #243과 공개 #139의 검색 질문 중복도 따로 확인한다.
- `fetched_at`만으로 정책 시행연도·적용 대상의 최신성을 증명할 수 없고, 현재 원고에 구조화된 시행일 메타데이터가 없으므로 일반적인 `stale effective date` 자동 판정은 추가하지 않았다. 제목 단어/공식 URL만으로는 질문의 의미상 중복을 확실히 판정할 수 없어 중복 로직도 변경하지 않았다. 독립된 최신 자료 확인 또는 검색 수요 측정을 수행했다고 주장하지 않는다.
