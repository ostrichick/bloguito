### #127 홈택스 ‘직접 조회 CTA’ — **FAIL / 도착 완료 UNVERIFIED**

09:25 공개 REST에서 #127에 `.bloguito-cta`와 `.bloguito-cta a`가 **각각 0개**다. 모바일 홈택스 URL `https://mob.tbht.hometax.go.kr/jsonAction.do?actionId=UTBRDAAA03F001` 한 건은 **오직 공식 출처 목록(`ul.source-list`)의 문헌 링크**이며 CTA 버튼이 아니다. 새 익명 HTTP GET은 **200**, 최종 호스트·경로 동일, 제목 `국세청 차세대 모바일`, 환급 관련 문구 존재를 확인했다. 그러나 이 문자열과 HTTP 200만으로 **미수령 환급금 직접 조회 폼을 표시한다거나 로그인 후 조회가 성공한다는 주장 불가**. 이전 9/22 격리 Edge에서 모바일 링크가 홈택스 메인으로 이동한 관측과 모순되지 않는다. **‘정확한 조회 화면으로 바로 보내는 CTA 존재’라는 기능 요구는 FAIL**, 공개 출처 URL의 HTTP 접근성은 PASS, 실제 조회 입력·완료는 UNVERIFIED. `ops-qa/links-official-summary.json`.
