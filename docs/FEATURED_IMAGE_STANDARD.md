# Bloguito 대표 이미지 표준

이 문서는 일반 정보글과 행사 글의 **대표 이미지**에 적용하는 현행 서술형 규약이다. 캔버스 크기, 글자 수, 모델, 후보 수, 금지 폰트 등 코드가 읽는 값은 `agent-publisher/editorial_policy.json`의 `featured_image_policy`가 정본이다. 행사 포스트의 추가 후보 비교 규칙은 [EVENT_POST_STANDARD.md](EVENT_POST_STANDARD.md)를 우선한다.

## 1. 목적

대표 이미지는 본문 전체를 축약한 포스터가 아니라 글의 주제를 한눈에 알아보게 하는 현대적인 에디토리얼 커버다. 상세 조건·가격·날짜·준비물·체크리스트를 이미지 한 장에 나열하지 않는다.

## 2. 일반 정보글 기본 구성

- 기본은 **왼쪽 세로 중앙 텍스트 + 오른쪽 단일 장면**이다.
- 왼쪽에는 선택적 소형 라벨, 큰 메인 제목 1~2줄, 짧은 보조 문구 한 줄까지만 둔다.
- 오른쪽에는 글의 행동을 설명하는 사람·집·스마트폰·PC·문서·제품 등 하나의 장면을 둔다.
- 제목 전체를 이미지에 반복하지 않고 핵심 질문만 짧게 압축한다.
- 줄바꿈은 의미 단위로 고정하며 숫자·단위·조사·핵심어를 어색하게 쪼개지 않는다.
- 얼굴, 머리, 손, 핵심 오브젝트가 잘리지 않아야 한다.

## 3. 한글과 서체

- 생성 모델에 읽을 수 있는 한글을 직접 그리게 하지 않고, 정책이 허용한 디스플레이 서체로 로컬 합성한다.
- 일반 시스템 고딕·본문용 기본 산세리프를 대표 이미지의 보이는 한글에 임의 fallback하지 않는다.
- 지정된 서체를 찾지 못하거나 고정 줄 계획을 유지할 수 없으면 저품질 대체본을 게시하지 않고 생성 실패로 처리한다.

## 4. 스타일

- 현대적, 미니멀, 에디토리얼, 넓은 여백, 하나의 분명한 초점을 기본으로 한다.
- 오래된 웹 배너, 관공서 전단지, 클립아트 콜라주, 아이콘 행렬, 현금·동전 나열, 과도한 화살표·리본·그라데이션·광택을 피한다.
- 생활행정은 실제 서비스 행동, 비용 비교는 실제 제품·영수증·가격 상황, 복지는 신청자의 생활 상황을 중심 장면으로 사용한다.
- 공연·콘서트는 검토된 공식 홍보 이미지를 우선하며 얼굴·공연명·분위기를 보존하고 파괴적인 중앙 크롭을 피한다.

## 5. 생성과 검수

생성 프롬프트는 목적 → 주제 → 중심 피사체 → 구도·안전 여백 → 텍스트 계획 → 스타일 → 금지사항 순으로 작성한다. 자동 경로에서는 먼저 텍스트 없는 장면을 만들고 한글은 후처리한다.

업로드 전에 최소한 다음을 실제 결과물로 확인한다.

- 주제가 한눈에 보이는가
- 단일 중심 장면과 충분한 여백이 있는가
- 한글이 정확하고 의미 단위 줄바꿈이 유지되는가
- 얼굴·손·문서·제품이 잘리지 않았는가
- 모바일 썸네일에서도 식별 가능한가
- 데스크톱에서 균형이 맞는가
- 오래된 배너·전단지처럼 보이지 않는가

자동 생성·공식 포스터 재구성 경로는 정책이 요구하는 비전 검수를 통과해야 한다. 검수 실패 후에도 고품질 결과를 얻지 못하면 로컬 클립아트나 도형 fallback을 WordPress 대표 이미지로 사용하지 않는다.
