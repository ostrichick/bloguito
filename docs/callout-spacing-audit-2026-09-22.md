## 검증과 적용 경계

- 새 테스트 포함 레이아웃 계약 검사 **4건 통과**, WordPress 운영 컨테이너에서 파일 내용을 표준입력으로 전달한 `php -l` **문법 오류 없음**, `git diff --check` 통과. 문법 점검 시 서버 파일은 생성·변경하지 않았다.
- 레이아웃 두 테스트 파일 전체 9건을 실행했을 때 **7건 통과·2건 실패**했다. `test_article_layout.py`의 두 STEP 문구 기대값이 현재 렌더러의 단일 절차 STEP 생략 동작과 일치하지 않는다. 이 검사 파일과 실제 렌더러는 이번 작업에서 수정하지 않았으므로, 상자 여백 변경으로 발생한 회귀로 확인된 것은 아니다. 먼저 실행했을 때는 `PYTHONPATH` 누락으로 import 실패했고, 환경변수를 운영 가이드대로 설정해 재실행하여 위 결과를 얻었다. 별도 테스트 정리는 수행하지 않았다.
- 브라우저 DOM의 CSS 실제 적용 전후 시각 비교와 360px/390px·확대 화면 검사는 미검증이다. 현재 단계의 CSS는 소스 수준의 수정이며 운영 서버에는 설치하지 않았다. 기존 공개 글 본문 내용·제목·상태·발췌문, 테마 옵션 및 WP DB는 변경하지 않았다.
