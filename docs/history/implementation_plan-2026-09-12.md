## User Review Required

> [!IMPORTANT]
> 1. **크론 스케줄 시간대 확인**:
>    - 일일 자동 포스팅: **매일 아침 08:00 KST** (`run_daily.sh`)
>    - 일일 DB 자동 백업: **매일 새벽 04:00 KST** (`backup_daily.sh`)
> 2. **WP Super Cache 실제 가동**:
>    - `$cache_enabled = true;` 적용 시 방문자 페이지가 정적 HTML로 캐싱되어 1GB RAM 환경에서 CPU/DB 부하를 80~90% 절감합니다. 관리자 로그인 시에는 캐시가 자동 우회됩니다.
> 3. **MariaDB 64MB 메모리 캡(Cap) 적용**:
>    - OOM(메모리 부족 킬러) 방지를 위해 `innodb_buffer_pool_size = 64M` 적용 시 컨테이너 재시작이 1회 수반됩니다 (다운타임 약 2초).

### Component 3: 서버 인프라 및 DB 최적화 (1GB RAM Tuning & Security)

#### [NEW] MariaDB 메모리 최적화 설정 (`/etc/mysql/conf.d/custom.cnf`)
```ini
[mysqld]
innodb_buffer_pool_size = 64M
max_connections = 50
key_buffer_size = 16M
```
- MariaDB가 예기치 않게 호스트 1GB 메모리를 과도하게 점유하여 시스템이 다운되는 현상 영구 방지.

#### [MODIFY] 워드프레스 보안 강화 (`/var/www/html/.htaccess`)
```apache
# Block XML-RPC brute-force and DDoS
<Files xmlrpc.php>
order deny,allow
deny from all
</Files>
```
- 외부 봇들의 무차별적인 `xmlrpc.php` 핑백 및 브루트포스 공격을 Apache 웹서버 레벨에서 403 차단하여 불필요한 PHP/DB CPU 소모 제거.

### Component 4: 자동화 및 데이터 백업 체계 (Automation & Backup)

#### [NEW] [backup_daily.sh](file:///home/ubuntu/agent-publisher/backup_daily.sh)
- 기능:
  1. `docker exec wordpress_app wp db export`로 MariaDB 전체 데이터베이스 덤프.
  2. `gzip` 압축하여 `/home/ubuntu/backups/db_backup_YYYYMMDD_HHMMSS.sql.gz`로 저장.
  3. 최근 7일이 지난 백업 파일 자동 정리 (`find ... -mtime +7 -delete`).
  4. 백업 성공 여부 로깅.

#### [MODIFY] Crontab 스케줄 등록
```bash
# 매일 새벽 4시 DB 자동 백업
0 4 * * * /home/ubuntu/agent-publisher/backup_daily.sh >> /home/ubuntu/agent-publisher/backup.log 2>&1

# 매일 아침 8시 카테고리별 자율 발행 파이프라인 가동
0 8 * * * /home/ubuntu/agent-publisher/run_daily.sh
```
