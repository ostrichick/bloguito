# 기존 게시물 7건: 공식 근거 결합 전문·승인 전 비교 (2026-09-22)

## 작업 범위와 판정

담당 기존 공개 WordPress 게시물은 **#219, #220, #218, #243, #139, #127, #125** 총 7건이다. 각 게시물마다 공식 출처에 연결된 개별 편집 브리프, 독립적으로 읽을 수 있는 완성 원고, 문단·표 행별 원문 인용을 보관한 JSON 번들, 렌더링된 HTML, 실제 운영 WordPress 저장 원문과 수정안의 비교, 변경 텍스트 diff, 후속 승인용 manifest를 생성했다. **실제 운영 게시물은 수정하지 않았다.** 서버 배포, 스케줄러 등록, Git stage/commit/push도 하지 않았다.

수집한 출처와 초안은 검토 가능한 실질적 산출물이다. 그러나 **Gemini `gemini-3.5-flash` 글 생성 요청 전 7건이 HTTP 429 `RESOURCE_EXHAUSTED`를 반환했고, 독립 모델 검토 역시 정상 수행되지 않았다.** 이에 글 본문은 공식 원문을 읽고 직접 작성했으며 모든 번들에 `review`를 붙이지 않았다. 기존 승인 게이트가 전 7건을 차단했다. 문서의 `사전 규칙 통과`는 출판 승인이 아니며 `승인 가능`이나 `배포 완료`로 해석하면 안 된다.

공통 루트: `tmp/legacy_audit_20260922/full-finance/`. 게시물별 `post-{ID}/`에는 다음 자료가 있다.

- 전기차 충전소의 위치·운영 정보 지도와 오피넷 지역별/경로별/도로별 주유소 가격 검색 기능을 구분했다. 정부 특별교통대책 기간 **9월 23~27일**을 제시하되 개별 실시간 충전기 운영이나 판매가격을 임의로 수치화하지 않았다.
- 공식 원문에서 2026 추석 **무료 급속충전 행사 지점, 제공량, 할인 가격은 확보되지 않았다.** 기사에 없는 혜택을 만들지 않았고 '지도 조회 가능 = 무료 충전 가능'이라는 등식을 배제했다. EV 지도와 로드플러스 일부 동적 원문은 수집기가 본문을 안정적으로 확보하지 못한 점을 출처 수집 상태에 기록했다.
- **시한 내 승인 불가:** 게시물의 유효기간이 추석 끝 **9월 27일까지로 불과 5일** 남아 정책 최소 잔여 유효기간 30일을 충족하지 못한다(`insufficient_useful_lifetime`). 별도 해당 ID 예외가 없으므로 임의로 에버그린 전환하지 않았다. `availability_not_verified`, `temporal_source_not_bound`, 재조회 해시 불일치, 독립 검토 미완료도 존재한다.

## 검증 기록과 적용 전 조치

`full-finance/final_verify.py` 및 `validation-summary.json`에서 다음 사항을 검증했다.

- **7/7** 완성 번들의 Pydantic `Plan` 형식 통과; 저장된 모든 공식 소스의 SHA-256과 원문 텍스트 일치; 문단·표 행 증거의 인용문이 지정 공식 텍스트에 실제 포함; 빈 증거 단락 없음.
- **7/7** 전체 라이브 WordPress 인벤토리 조회(40건)와 ID별 저장 원문을 별도로 비교해 ID·게시상태·제목·전체 `post_content`가 동일함을 확인했고, 각각 private 백업과 SHA-256을 기록했다. 독립 승인 패키지 `approval-manifest.json`의 원문 SHA도 **7/7** 일치했다.
- **7/7** 번들 렌더 HTML↔원고 미리보기↔승인 패키지 제안 SHA 일치, 원본 제목 보존, 비교파일 존재; 검증 결과 **무결성 오류 0건**. 기존 `editorial_cli.py check`는 예상대로 **7건 모두 종료코드 2(승인 차단)**. `#218, #243, #127`의 *리뷰 전 규칙*만 `ready`; 전체 승인 0건.
- 수집 시점 공식 소스 전체 해시↔승인 스크립트의 라이브 재조회 일치는 **#218·#243 두 건**. #220·#139·#127·#125·#219는 불일치, 일시적 페이지 카운터/동적 주변 링크 등의 가능성이 있으나 **본문 불변을 단정할 수 없으므로** 다시 받아 근거 내용을 비교한 후 새 해시에서 재검토해야 한다. 특히 국세청 `nts.go.kr` 접속 경로는 `www.nts.go.kr`에만 적용되는 조회수 제거 코드와 범위가 달라 원문 전체 HTML의 방문 카운트가 증가하면 달라질 수 있는 점을 확인했다. 이 관찰은 해시 실패를 무시할 이유가 아니다.

후속 승인 절차는 (1) 각 상태 파일의 실제 블로커를 해결하고, 특히 #139/#125 주제 중복 여부와 세금포인트 표기 검증 충돌을 해결할 수 있는 출처·문안 검토, #219 시한 문제, #220 기간 증거를 검토한 뒤 (2) 현재 제안과 다시 받은 공식 출처에 **독립 검토를 완료**, (3) 최신 라이브 WordPress 원문 SHA·공식 근거 전체 SHA 재확인과 승인 패키지 재생성 순서이다. **원고를 작성한 사람이 독립 검토를 수행한 것으로 간주해서는 안 된다.** 승인 없이 원고나 excerpt를 WordPress에 반영하지 않는다.

## 조사 기록·도구 제한

공식 원문 최초 및 대체 수집 기록은 `official-source-captures.json`, `alternate-source-captures.json`, `holiday-official-captures.json`, `tax-home-captures.json`에 보존했다. 소스 404/30x/동적 빈 본문은 해당 시점의 실패로 정확히 기록하고 다른 문서에서 실제 정보를 확보한 경우에만 사용했다. `generate_articles.py`의 Gemini 생성 실패는 각 `post-{ID}/generation-error.txt`에 남아 있으나 이후 `manual_bundles.py`로 전 건 원고 생성에 성공했다. 자동 생성 모델 호출 결과와 직접 작성된 원고를 혼동하지 않는다. 원고/미리보기 내부에는 SSH 인증정보, 사이트 API 비밀키, 사적인 사용자의 보험·납세 조회 결과를 포함하지 않았다.
