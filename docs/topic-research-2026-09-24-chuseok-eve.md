## 신규 후보

### 1. 명절 음식 보관·재가열 방법

권장 검색 질문: “명절 음식을 많이 만들었을 때 어떻게 식혀 냉장하고 다시 데워 먹어야 하나요?”

제목 후보: “명절 음식 보관·재가열 방법: 냉장 시점, 해동·재냉동, 안전한 조리 온도”

근거:
- 식품의약품안전처가 2026-09-21 “추석 명절 안전한 장보기·음식 보관 수칙 안내”를 발표했다.
- 공식 원문: https://www.mfds.go.kr/brd/m_99/view.do?seq=50367
- 추석 직전 장보기·대량 조리 시점과 맞고, 추석이 지난 뒤에도 설·제사·대량 조리 상황에 반복 사용 가능한 질문이다.
- 현재 WordPress 재고에서 독립적인 음식 보관·재가열 글은 확인되지 않았다.

편집 방향: “2026 추석 당일 식중독” 같은 단기 제목보다 장보기 순서, 이동 중 보냉, 충분한 가열, 빠른 냉각·냉장, 해동 식품 재냉동 금지, 저장 음식 재가열을 질문별로 정리하는 에버그린 구조가 적합하다.

### 2. 인천공항 출국장 대기시간·예상 혼잡 확인

권장 검색 질문: “인천공항에 가기 전에 터미널별 출국장 혼잡 시간을 어디서 확인하나요?”

제목 후보: “인천공항 출국장 대기시간 확인: T1·T2 예상 혼잡도와 시간대별 승객 조회”

근거:
- 인천국제공항은 2026-09-24와 9월 25일을 포함한 시간대별 출국 승객 예고 현황을 공식 페이지에서 제공하고 있다.
- 공식 예고 페이지: https://www.airport.kr/ap_ko/884/subview.do
- 연휴 출국 수요가 몰리는 시점에 즉시 행동 가능한 질문이며, 공항의 실시간·예고 조회 서비스 자체는 특정 추석 날짜에만 쓰이는 정보가 아니다.
- 현재 WordPress 재고에서 인천공항 혼잡·출국장 대기시간 전용 글은 확인되지 않았다.

편집 방향: 특정 시간대가 “항상 덜 붐빈다”고 고정하지 않고, 공항 공식 화면에서 터미널·날짜별 예상 혼잡을 직접 읽는 방법과 업데이트 시각, 체크인·보안검색을 구분해 설명한다.

### 3. 택배·명절선물 사칭 스미싱 확인·신고

권장 검색 질문: “택배 주소 오류나 명절 선물 문자에 링크가 왔을 때 스미싱인지 어떻게 확인하고 신고하나요?”

제목 후보: “택배 주소 오류 문자, 눌러도 될까? 스미싱 확인·신고 방법과 118·보호나라 이용법”

근거:
- 개인정보보호위원회는 2026-09-11 명절 택배·선물 및 가족·지인 사칭 스미싱·피싱 주의를 안내했다.
- 정책브리핑: https://www.korea.kr/multi/visualNewsView.do?newsId=148971632
- 과학기술정보통신부는 2026-09-18 출처 불명 URL·전화번호를 누르지 말고, 의심 문자는 카카오톡 보호나라 채널 또는 118로 상담하며 피해 발생 시 112 신고를 안내했다.
- KISA의 상시 안내도 118, 카카오톡 보호나라 채널, 통합신고 경로를 제공한다: https://www.kisa.or.kr/1020601
- 현재 WordPress 재고에서 스미싱 전용 글은 확인되지 않았다.

편집 방향: 특정 추석 캠페인 소개보다 “문자 수신 → 링크 누르기 전 확인 → 보호나라/118 → 피해 발생 시 112”의 반복 가능한 절차를 중심에 둔다.

### 4. 명절 전 장거리 운전·조리 화재 예방

권장 검색 질문: “명절 전날 장거리 운전과 음식 준비 때 사고를 줄이려면 무엇을 확인해야 하나요?”

제목 후보: “명절 전날 사고 줄이는 체크리스트: 장거리 운전과 음식 조리 화재 예방”

- 공식 정책브리핑: https://admin2.korea.kr/briefing/pressReleaseView.do?gubun=pressRelease&newsId=156782664&pageIndex=1&repCode=A00031
- 현재 WordPress 재고에서 이 두 위험을 묶은 생활안전 글은 확인되지 않았다.

편집 판단: 시의성은 높지만 음식 보관·공항·스미싱보다 검색 질문이 넓다. 쓰려면 “교통사고 예방”과 “주택 화재 예방” 중 하나로 더 좁히는 것이 좋다.
