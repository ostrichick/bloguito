# 2026-09-15 글 형식 복원 기록

## 확인된 문제

공통 검증 렌더러 전환 과정에서 기존 글의 `핵심요약` 박스와 번호형 소제목이 사라졌고, 문단마다 출처 링크가 반복되어 읽기 흐름이 끊겼다. 두 임시글(112, 113)의 사실·초안 상태·대표 이미지는 유지해야 했다.

## 적용한 변경

- 공통 렌더러가 첫 답변을 `핵심요약` 박스로 표시하고 본문 sections에 `1.`, `2.`, `3.` 번호를 자동 부여한다.
- FAQ를 별도 상자형 영역으로 묶고, 출처 링크는 글 하단 `공식 출처` 목록에 한 번만 표시한다.
- 제목에 이미 번호가 있어도 중복 번호가 생기지 않도록 정리한다.
- 사용자가 직접 고친 초안을 덮어쓰지 않도록 기존 본문·제목·상태를 재확인하는 `reformat` 경로를 추가했다.
- 자동 작성 지침에 단계형 절차와 준비물 체크리스트 설계 원칙을 추가했다.

## 검증 범위

로컬 전체 테스트 107개 통과. 편집 시스템 테스트 30개 통과 후 OCI 서버에 배포했으며, 서버 롤백 백업은 `editorial-20260915T025306Z`로 생성됐다. 서버에서 112·113을 초안 상태로 유지한 채 새 렌더러로 재서식화했다.

키워드 검색량 자체는 측정하지 않았으므로 유입을 보장하지 않는다. 다음 작성부터는 brief 단계에서 ‘현재 사람들이 입력할 구체 질문’을 먼저 승인하고, 본문은 그 질문을 해결하는 단계·체크리스트 구조로 작성한다.
