# #922 건강보험 임의계속가입 비교 — 2026년 결정론적 산술 예시

## 검증된 공식 입력

- 국민건강보험공단, [2026년도 보험료율 인상 안내](https://edi.nhis.or.kr/portal/images/popup/20251204_pop01longdesc.html): 건강보험료율 7.19%, 장기요양보험료율 0.9448%, 장기요양보험료 산식은 건강보험료에 `0.9448 ÷ 7.19`를 곱함.
- 법제처 국가법령정보센터, [보험료 경감고시 제9조](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000270516&chrClsCd=010201): 임의계속가입자 보수월액보험료 100분의 50 경감.
- 법제처 국가법령정보센터, [국민건강보험법 제107조](https://law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=1013122437), [노인장기요양보험법 제64조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0064&lsiSeq=281921&urlMode=lsScJoRltInfoR), [국고금 관리법 제47조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1028611839): 보험료 계산에서 10원 미만 끝수를 제외함.
- 법정 보수월액은 과거 12개월의 보수월액보험료가 산정된 보수월액 평균(단순 월급·실수령액으로 대체하지 않음).

## 메타데이터 계약

`calculations`에 `operation: voluntary_insurance_2026_example`을 사용한다.

| 필드 | 의미 |
| --- | --- |
| `average_remuneration_won` | 퇴직 전 최근 12개월 평균 보수월액(원), 가상 사례 입력 |
| `regional_total_won` | 장기요양보험료까지 포함한 월 지역보험료(원), 가상 비교 고지액 입력 |
| `health_won` | 2026년 임의계속 보수월액 건강보험료 산술값 |
| `long_term_care_won` | 임의계속 장기요양보험료 산술값 |
| `voluntary_total_won` | 임의계속 두 보험료 월 합계 |
| `advantage` | `voluntary`, `regional`, `equal` |
| `monthly_gap_won` | 두 선택 월 차액의 절댓값 |
| `twelve_month_gap_won` | 월 차액 × 12 (12개월 조건 동일 가정) |

산술값은 `health_won = ((보수월액 × 719) // 20000) // 10 × 10`, `long_term_care_won = ((health_won × 9448) // 71900) // 10 × 10`으로 **각 보험료에서 10원 미만 버림**을 사용한다. 이 단수처리는 위 법령에 근거하지만 가상 비교값으로 실제 공단 고지액의 모든 경감·정산을 보증하지 않는다. 독자 문구의 입력·결과는 각각 원 단위로 표시한다.

반드시 같은 행 또는 문단과 표 공통 설명에 `가정`, `보수월액`, `지역보험료`, `장기요양 포함`, `10원 미만 버림`, `보수 외 소득`, `실제 고지`, `12개월 동일`이 보이게 한다. 연결된 official source evidence는 2026년 두 요율과 50% 경감, 10원 미만 단수처리를 모두 담아야 한다. 실 지역보험료는 지역가입자의 소득·재산과 세대별 조건으로 달라지므로 이 연산에서 역산하지 않는다. 지역보험료 가정값을 실제 고지액·평균값으로 쓰지 않는다. 보수 외 소득월액보험료, 다른 경감·정산, 세대 합산, 피부양자 여부는 본 연산에서 제외되므로 별도 확인을 안내한다. 이후 연도에 적용하는 근거로 확장하지 않는다.

## 샘플 검산

평균 보수월액 300만원의 2026년 임의계속 산술값은 건강보험 107,850원, 장기요양 14,170원, 월 합계 122,020원이다.

- 지역보험료(장기요양 포함)를 180,000원으로 가정하면 임의계속이 월 57,980원 낮고, 12개월 동일 조건 가정 시 695,760원 차이.
- 지역보험료(장기요양 포함)를 100,000원으로 가정하면 지역보험이 월 22,020원 낮고, 12개월 동일 조건 가정 시 264,240원 차이.
- 보수월액 500만원일 때 임의계속 월 203,370원 산술값과 가정 지역보험료 203,370원은 동일.

작업 대상 #922의 A/B/C 예시: 300만원·지역 250,000원 → 임의계속 122,020원/월 127,980원 절약·12개월 1,535,760원, 500만원·지역 150,000원 → 임의계속 203,370원/지역이 월 53,370원 절약·12개월 640,440원, 400만원·지역 170,000원 → 임의계속 162,690원/월 7,310원 절약·12개월 87,720원. 모두 같은 요율·조건 12개월 유지의 가상 계산이다.
