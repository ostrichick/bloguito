# Bloguito Evergreen 주제 조사 — 2026-09-25

## 1. 조사 목적과 한계

목표는 단기 시즌 글이 아니라 6개월 이상 반복적으로 검색될 가능성이 있는 생활정보 질문을 찾고, 현재 Bloguito의 주제 공백과 실제 검색결과 경쟁 상황을 함께 고려해 다음 작성 후보를 정하는 것이다.

이번 조사는 월간 검색량이나 Search Console 실제 노출량을 측정한 키워드 리서치가 아니다. Site Kit by Google 플러그인이 운영 WordPress에서 활성 상태인 것은 확인했지만, 이번 작업 환경에서는 Search Console의 질의별 노출·클릭 테이블을 안전하게 읽을 수 있는 연결을 확보하지 못했다. Google Trends 또한 현재 웹 도구에서 직접 열리지 않았다. 따라서 아래 점수는 트래픽 예측치가 아니라 편집 우선순위 점수다.

검색량, CTR, 검색 순위, CPC는 모두 미측정이다. 검색결과에 글이 많다는 사실도 검색량이 높다는 뜻으로 사용하지 않는다.

공개글 36편 중 제목에 추석이 들어간 글이 이미 9편이다. 사이트 포트폴리오의 25%가 특정 명절 키워드에 묶여 있다. 다음 evergreen 투자에서는 추가 명절 글보다 상시 생활절차를 우선한다.

### 기초연금 일반 가이드

#101, #79, #55가 이미 존재한다. 새로운 독립 과제가 없다면 기존 대표 글과 하위 글을 강화한다.

### 미환급금 종합 리스트

#139가 이미 넓은 허브 역할을 하고 #243, #220, #127, #125가 존재한다. 또 다른 숨은 돈 N가지 글은 중복 위험이 크다.

### 독감 일반 일정

#63과 #81이 존재한다. 별개의 해결과제가 아니라면 새 URL을 추가하지 않는다.

### 가족관계증명서 일반, 상세, 특정부터 시작

좋은 evergreen 질문이지만 현재 검색결과에 유사한 최신 독립 글이 다수 확인됐다. 첫 5편보다 경쟁 우선순위가 낮다.

## 8. 다음 검증 단계

이 조사에서 가장 큰 미측정 값은 실제 검색 수요다.

다음 단계에서는 다음 순서가 적절하다.

1. Search Console에서 최근 28일·90일 쿼리 / 페이지 / 노출 / 클릭 / 평균순위를 확보한다.
2. 기존 글이 이미 노출되는 인접 키워드와 위 20개 후보를 대조한다.
3. Google Trends와 네이버 데이터랩으로 후보의 상대적 계절성을 확인한다.
4. 1~10위 후보는 각 검색어별 상위 결과 5~10개를 수동 표본으로 저장하고, 가격/비용, 조건, 예외, 직접 행동 링크, 최종수정일 누락을 기록한다.
5. 최종 3~5개만 원고 단계로 넘긴다.

Search Console 데이터가 확보되면 이 문서의 점수를 다시 계산해야 한다. 현재 점수는 트래픽 전망이 아니라 지금 무엇을 조사·작성하는 것이 가장 효율적인가를 위한 우선순위다.
