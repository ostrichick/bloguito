## 범위와 판정의 의미

2026-09-22 KST 12시대, 공개 WordPress REST `GET /wp-json/wp/v2/posts?status=publish&per_page=100&_fields=id,date,modified,link,slug,title,excerpt,content,status` 응답 `HTTP 200`, `X-WP-Total: 30`을 확인하여 **공개 30편의 현재 렌더링 HTML 전체**와 텍스트를 별도 스냅샷에 보관했다. 임시·예약·비공개·대기 게시물은 이 공개 전수에 포함되지 않는다. 보존 위치: `tmp/legacy_audit_20260922/content-worker1/live-public-posts-raw.json`, `live-public-posts-text.json`. 게시물이 동시 수정되면 이 스냅샷을 다시 받아야 한다. 기존 `docs/published-content-review-2026-09-20.md`의 26편은 과거 집계로만 취급한다.

**우선순위는 편집 작업의 순서**다. P0=확인한 공식 자료와 실제 본문 사이의 핵심 안내 누락·근거 연결 오류로 즉시 재작성 검토, P1=높은 독자 질문 누락 또는 중요한 시한·대상별 세부 안내 보강, P2=자료 변경·실시간 의존도에 따른 후속 공식 재검증, P3=이미 종료·유지 목적이 명확하거나 상대적으로 후순위인 점검. 우선순위는 글 전체의 정확성 인증이나 오류 확정 판정이 아니다. 사실 오류 확인은 `확인`, 직접 자료와 비교하지 못한 것은 `미확인`으로 구분한다. 검색량·유입·광고 성과는 측정하지 않았다.

구형 본문은 25편이다. 기존 공통 점검은 그중 녹색 요약 상자의 잘못된 닫는 `</p>`가 출력되는 **24편**을 확인했고, #85는 별도 구형 구조이나 해당 태그 오류는 없다(`docs/callout-spacing-audit-2026-09-22.md`). 형식 교정은 별도 담당의 변경·운영 적용 결과를 확인할 후속 과제이며, 본 문서는 게시물 콘텐츠만 다룬다. 신규 형식 5편은 #218·#225·#243·#304·#349. 이 통계는 콘텐츠 사실 정확성 판정과 구분한다.

## 생성 산출물 및 편집 검증 상태

작업은 `tmp/legacy_audit_20260922/content-worker1/`와 **이 문서 하나**에서만 수행했다. `live-public-posts-raw.json`/`live-public-posts-text.json`은 공개 30편의 실제 응답·텍스트. `public-inventory-only.json`은 공개 글만 담는 검사 참고자료, `inventory-excluding-{ID}.json`은 현재 글만 제외한 구조화 검사 입력(비공개 게시물까지 확인한 실제 운영 inventory와 다름). `brief-{55,79,103}.json`, `bundle-{55,79,103}.json`, `evidence-matrix-{55,79,103}.json`은 각각 공식 출처·원고·원문 연속 인용 매핑을 포함한다. `post-{55,79,103}-public-rest-sha256.txt`는 **공개 REST의 렌더된 HTML** 해시일 뿐, 인증된 원본 `post_content` 교체 승인을 위한 해시가 아님.

실제 `editorial_cli.py sources`는 #55 4개, #79 3개, #103 2개 공식 URL을 성공적으로 가져와 출처 ID/문자열/SHA256/읽은 시각을 남겼다. 처음에는 #79 동적 복지로 화면이 본문 길이 3자로 추출되어, #103 예방접종도우미는 Python TLS 협상 오류로 이 경로의 수집이 실패했다. 출처를 은폐하거나 실제로 못 읽은 페이지의 문장을 생성하지 않고, 안정적으로 읽힌 현재 복지부·질병청의 공식 원문으로 범위를 정했다. 두 증상은 추가 조사 필요.

같은 **공통** `editorial_cli.py check` 실행 결과 세 후보 모두 `needs_review`. 문단별 출처는 실제 URL 텍스트에서 고른 연속 인용이고 `number_without_evidence`는 수정 후 최종 3건 모두 소거. 공통 차단 이유: `availability_not_verified`, `temporal_source_not_bound`, `review_not_bound_to_current_content`, `review_stale`, `semantic_review_failed`; #55는 공개 #101 등과 공통 공식 URL이 겹치므로 `duplicate_topic` 추가. 이는 단순한 모델 형식 실패가 아니라 현행 편집 검사의 일정형 기간/중복 검사에 적합한 기존 공개 글의 정식 처리 검토가 필요함을 뜻한다. 사전 검사가 `ready`가 아니므로 `review`가 독립 모델을 호출하기 전에 차단됨. 별도 검토자가 6개 의미 항목을 모두 승인한 원고라고 보고하지 않는다. 정책에 맞지 않는 임의 후기한 가정·복지 주제 `evergreen` 전환·중복 inventory 은폐로 통과시키지 않는다. 지역별 실제 병원 검색, 복지로 JS 페이지 조작, 로그인/신청 완료, 전체 문단의 제3자 독립 사실 검증, 모바일 화면 실측은 **미검증**이다.
