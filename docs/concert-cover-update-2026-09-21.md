- 사용자는 제공한 로이킴 공식 포스터를 크롭·편집하여 기존 블로그 게시물에 업로드하도록 요청했고, 이어 제공한 무명전설 전국투어 포스터에도 같은 제작·업로드를 요청했다.
- 실제 WordPress 공개 게시물 #99(로이킴 서울), #70(무명전설 12월 25일 수원 앵콜)을 확인했다. 변경 전 두 게시물의 `post_content`에는 이미지가 없지만, GeneratePress 테마는 이미 각각 대표 이미지를 본문 위에 별도로 표시했다. 동일 이미지를 본문에 중복 삽입하지 않고 **대표 이미지 교체**로 상단 시각 이미지를 갱신했다.
- 이미지와 메타데이터만 변경했다. 글의 제목·본문·슬러그·공개 상태, 플러그인, 운영 코드에는 손대지 않았다.

## 운영 반영·검증

- 업로드 직전 각 게시물의 WordPress 원본 JSON·대표 이미지 ID·본문 SHA256을 로컬 및 서버 비공개 백업으로 저장: `/home/ubuntu/agent-publisher/data/editorial_runs/concert-covers-20260921/post-99-before.json`, 동일 폴더의 `post-70-before.json`. 이전 미디어 100, 71은 삭제하지 않았다.
- 실제 WordPress에서 각각 공개 상태(`publish`), 제목·슬러그·본문 SHA256이 유지됐고 `_thumbnail_id`는 의도대로 354, 355로 변경된 것을 확인했다. 이미지 대체 텍스트도 두 첨부물에 저장돼 있다.
- [로이킴 공개 글](https://lifeinfo24.org/?p=99) 및 [무명전설 공개 글](https://lifeinfo24.org/?p=70) HTTP 200, HTML에 새 `bloguito-99-cover.webp` 및 `bloguito-70-cover.webp` 각각 포함. 이미지 주소 자체 HTTP 200 및 바이트 크기(58,690 / 137,990) 일치.
- 상단 대표 이미지가 테마에서 별도 출력되는 구조이므로 중복 본문 이미지 추가 없음. 수동 모바일 실기기 시각 검사는 수행하지 않았다.
- 롤백이 필요하면 게시물별 사전 백업과 현행 상태를 먼저 대조한 후 대표 이미지 ID를 기존 100·71로 되돌린다. 원고·게시물 본문을 덮어쓰는 복원은 필요하지 않다.
