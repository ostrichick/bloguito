## 변경 이유

## 편집·운영 범위

WordPress의 공개·임시·예약·검토 상태 글 목록을 먼저 조회해 동일 대상의 기존 제목과 중복 여부를 검토했다. 기존 무명전설·에너지바우처·다른 에이전트의 새 글은 수정하지 않았다. 두 신규 글에 요약과 자체 제작한 한글 대표 이미지를 추가했다.

사용자에게 검증을 떠넘기는 FAQ, 내부 검증 날짜 설명, 일괄 보장 부인 문구를 넣지 않았다. 주민센터·수거업체 사전 전화는 공식 배출 절차이므로 행동 단계로 설명했다.

두 글은 수동으로 공식 자료를 검토해 작성한 임시글이다. 자동 장문 생성 파이프라인이 이 품질을 구현했다고 간주하지 않는다. 이번 작업에서 자동화 코드 배포·크론 변경·공개 발행은 하지 않았다.

## 검증

- WP-CLI로 두 글의 `draft` 상태 및 대표 이미지 ID를 재조회했다.
- 저장된 본문 SHA256와 최종 준비 원고의 SHA256 일치를 확인했다.
- 운영 `draft_posts.json`에 두 글을 추가하고 기존 항목을 보존했다. 공개 글 색인에는 추가하지 않았다.
- 로컬 대표 이미지의 한글 표시와 잘림을 확인했다. 관리자 로그인 상태의 브라우저 렌더링 검증은 수행하지 않았다.
- 코드 변경 없는 원고·문서 작업으로 회귀 테스트를 재실행하지 않았다.
