# Bloguito · Antigravity 상시 편집 규칙

루트 `AGENTS.md`를 적용한다. 글 작성·주제 선정·자동화 전 `docs/EDITORIAL_SYSTEM.md`와 `agent-publisher/editorial_policy.json`을 읽는다. 이 파일들이 현재 기준이며 과거 인계·감사 문서는 이력이다.

공식 원문, 공개·임시·검토 중인 글의 중복, 정보 유효기간을 확인한다. 수동 원고도 구조화하고 `agent-publisher/editorial_cli.py` 검토·검사·등록 경로를 따른다. 지침·근거를 읽지 못하거나 검사가 실패하면 등록을 보류하고 이유를 내부 기록에 남긴다. 독자에게 확인을 떠넘기거나 미확인 사실을 채우지 않는다. 기본은 임시글이며 명시적 승인 없이 공개·기존 공개 글 수정을 진행하지 않는다.
